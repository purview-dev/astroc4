## Inline DSL

Compiled and laid out at build time — a typo here fails the build.

```likec4 title="Inline" height=320
specification {
  element box
}
model {
  a = box 'Author' { icon tech:markdown }
  b = box 'Build' { icon tech:astro }
  c = box 'Reader'
  a -> b 'writes'
  b -> c 'serves'
}
views { view index { include * } }
```

## Picking a view

With several views, `view="…"` chooses one; otherwise the first is used.

```likec4 view="second" title="Second view" height=280 collapsible=false
specification { element box }
model { x = box 'X'  y = box 'Y'  x -> y }
views {
  view first { include x }
  view second { include * }
}
```
