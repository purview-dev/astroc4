A ` ```likec4 ` fence becomes a diagram, so use the `c4` alias to show source:

```c4
specification {
  color brand #0046BE
  element system { style { shape rectangle color brand } }
  tag public
}
model {
  site = system 'Docs site' {
    #public
    icon tech:astro
    link https://likec4.dev 'LikeC4'
  }
  reader -[https]-> site 'browses'
}
views {
  view index { include * where tag is #public }
  dynamic view walk { reader -> site 'GET /' }
}
```
