Syntax highlighting needs no configuration: the plugin reads the Langium
grammar from `likec4/likec4` and registers it with Expressive Code. There is no
`ec.config.mjs` in this playground.

A ` ```likec4 ` fence becomes a diagram, so use the `c4` alias to show source:

```c4
specification {
  color brand #0046BE
  element system { style { shape rectangle color brand } }
  tag public
}
model {
  site = system 'Docs site' {
    #public
    icon tech:astro
    link https://likec4.dev 'LikeC4'
  }
  reader -[https]-> site 'browses'
}
views {
  view index { include * where tag is #public }
  dynamic view walk { reader -> site 'GET /' }
}
```

Highlighting follows the version of the language you build against. Everything
here — `agent`, `predicateGroup`, `descriptionFile`, `instanceOf` — exists in
LikeC4 after `v1.59.4`, and is highlighted because the grammar is derived at
build time rather than maintained by hand:

```c4
model {
  chatbot = agent 'Chatbot' {
    descriptionFile ./chatbot.md
  }
  audience = person 'Audience'
}
deployment {
  prod = instanceOf chatbot
  prod.node = node 'us-east-1'
}
global {
  predicateGroup internals {
    include chatbot
  }
}
```
