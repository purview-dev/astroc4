# LikeC4 in plain Astro

This page is a real site: `astro.config.ts` has `astroc4()` from
`@purview-dev/astroc4/integration`, `@astrojs/mdx` and `astro-expressive-code`,
and `astroc4()` adds `@astrojs/react`. The project's config is
`src/likec4/likec4.config.ts`. There is no Starlight here — the diagrams, the fence
transform and the highlighting are the same code the Starlight plugin uses.

## A view from the model

`src/likec4/model.c4` is compiled by LikeC4's Vite plugin, which the integration
adds for you.

<LikeC4View viewId="index" height={320} />

## A fence, compiled at build time

` ```likec4 ` becomes a diagram in any `.mdx` page — the fence carries its own
model, so no project is needed.

```likec4 title="Inline, from the fence" height=240
specification { element box }
model {
  a = box 'Alpha'
  b = box 'Beta'
  a -> b 'calls'
}
views { view index { include * } }
```

## LikeC4 source stays source

` ```c4 ` is highlighted by Expressive Code with `likec4Language`, passed to
`expressiveCode()` in `astro.config.ts`. Outside Starlight there is no
`expressiveCode` option for the plugin to fill in, so that is the one thing the
site does itself.

```c4
specification {
  color brand #0046BE
  element system { style { shape agent color brand } }
}
```
